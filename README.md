# Capstone_project

My project (located in the branch feature/eirik-function) is broken down by labs. In lab1, where we are now, we have my Python project, a 7 function calculator. 
It performs Addition, Subtraction< Multiplication and Division.

In addition, it has 3 more functions that cover the Scientific
computations for Tangent, Sine and Cosine. The latter are in their
own file (PythonScientific.py) and are called via function from PythonCalc.

I added app.py to make a subprocess call to PythonCalc.py as it is the direct
controller or psuedo-main python file. I hope it generates conflicts. One solution is to utilize my app5.py per group suggestion.
